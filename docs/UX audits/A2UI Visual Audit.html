The Living Forge · principal visual & interaction audit · §5 + §6

The weld is real. The ember is leaking.

Visual + interaction lens only — type, color, motion, atmosphere, composition. Held mercilessly to the two rules that make or break this brand: the Weld as the one defining gesture, and ember as never-decorative. The motion language is genuinely distinctive and mostly correct. But the accent that's supposed to mean "I just made this" is baked into the logo, the wordmark, and three labels — so it means nothing. That fails the gate.

02 The ember leak, itemised

Every ember element in the kit, judged

The rule is binary: ember is the active weld, the active Step, the single primary CTA — and the spec-sanctioned bloom. Anything else dilutes the one signal the brand sells. Here is the full census.

  • Active weld hairline @keyframes weld-cool — legitimate. This is the gesture.
  • Primary CTA .btn-primary — legitimate, one per frame (Run / Practice / Forge / send).
  • Active Step dot .step.active — legitimate (Stepper not in the live scenario, but correct).
  • Radial bloom .forge-bloom — sanctioned by §5.1 as the brand's "single warm light source."
  • Logo diamond .brand-spark .d — LEAK. Persistent decorative ember in the header; present in every frame regardless of state.
  • "Forge" wordmark .brand-name b — LEAK. Decorative ember on static brand text.
  • "Forged" diff header .diff-after .diff-head — LEAK. A label, not an action; should match "Your prompt" in --ink-subtle.
  • Verdict sparkle icon .verdict Icon color=--ember — LEAK. Decorative accent on a static line.
  • SkillMap "ready" ring + edge .smap-node.ready / .smap-edge.ready — LEAK. Ember here means "opportunity," a 4th meaning; collides with "recency." Use a pulsing ring + dashed edge + size instead.
  • Composer focus icon .composer:focus-within .c-icon — minor leak; the focus ring already signals active. Keep the icon --ink.

Six decorative ember uses against four legitimate ones. On the intro alone, four embers sit at rest. The fix is entirely token-level and costs nothing visually except discipline — and it's the single highest-leverage move in this audit.

03 Top 3 highest-leverage fixes

Ranked by impact on brand distinctiveness

1

De-ember the persistent chrome

fixes gate · check 1, sharpens 4
This is the make-or-break move. Right now ember lives in the logo and labels, so when a surface actually welds, the warm flash has no contrast — the eye is already saturated with orange. Pull ember out of everything persistent; let the weld and the one CTA be the only warm things that aren't the bloom.
Was — ember as brand.brand-spark .d { background: var(--ember) }
.brand-name b { color: var(--ember) }
.diff-after .diff-head { color: var(--ember) }
Now — ember reserved.brand-spark .d { background: var(--ink) }
.brand-name b { color: var(--ink) }
.diff-after .diff-head { color: var(--ink-subtle) }

Net effect: at rest, the only ember in frame is the drifting bloom; the instant Jarvis forges, the weld is the only new warm thing — the signal lands. Impact: highest. It restores the brand's central claim.

2

Make "thinking" the hairline sweep — kill the skeleton

fixes check 7, sharpens 3 & 4
The skeleton rows are generic loading-slop and they muddy the two-accent system: "working" should be a single, unmistakable cool gesture, not a grey content placeholder. Replace the skeleton with the spec's gesture — a 1px --agent gradient sweeping the top hairline of the forming surface, stopping the instant the first component lands.
Was.thinking-block ::before height: 2px
+ .skel rows (skeleton)
Nowheight: 1px on the surface's own top hairline
no skeleton — just the sweep, ~1.4s loop

If a progressive mid-stream placeholder is wanted (the UX track asked for it), gate it to after the first component lands — never as the opening "thinking" signal. Impact: high. Cleans the cool half of the binary.

3

Deploy the display tier — give the grotesque a 44/64 moment

fixes check 12, adds scale to 5
General Sans is a characterful grotesque, but the kit caps at 24px — so it never reads as anything but a tidy sans. The system defines 64/44/28; use it. Promote the intro hero to ~44px / -0.02em, and make the results score a real 64px display moment (the number is the reward — let it be huge). While here, complete the weld gesture: add scale(.98) and tighten the rise to 8px.
Was.block h2 { font-size: 24px } /* the ceiling */
.weld-in welding { transform: translateY(10px) }
Now.block h2.hero { font-size: 44px; letter-spacing:-.02em }
score label → ~64px · transform: translateY(8px) scale(.98)

Impact: medium-high. It's the difference between "a calm dark app" and "a workshop with a voice."

04 The "too safe" call-out

Every surface is the same polite 860px card

Where it played it safe

The whole kit is a single centred 860px column of equal-weight rounded cards, each topping out at a 24px headline. That's the obvious, defensible reading of "single-column, content-led" — but the spec's actual instruction is "quiet chrome, LOUD content." Nothing in this mockup is ever loud. The diagnostic result — the emotional payoff, the moment the learner earns something — is rendered at the same scale and rhythm as the intro blurb. The forge never produces an event; it produces another card.

The sharper alternative: let a freshly-forged moment briefly own the frame. The results score becomes a 64px+ display number with deliberate asymmetry — ring pushed off-axis, the SkillMeters hung in generous negative space rather than stacked in a tidy column. Break the centred rhythm once, on the moment that matters, so the weld delivers a payload that looks different from everything around it. The mockup treats variety as risk; here the spec was inviting contrast, and contrast is exactly what would make "you can watch it being built" feel earned rather than asserted.

The motion is right, the restraint is right, the tokens are right. What's missing is the nerve to let one surface be three times bigger than the others. Fixes #1 and #3 together buy that nerve cheaply.
